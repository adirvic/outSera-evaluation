## Plano de desenvolvimento

### Fase 1: Estrutura do projeto
1. Gerar o projeto Spring Boot com Maven (`com.outsera.razzies`), Java 21, e criar `.gitignore` (incluindo `.idea/` e `target/`).
2. Em `application.yml`: H2 em memória, `ddl-auto` e um caminho de CSV configurável (`app.csv.path`, padrão `classpath:movielist.csv`). Isso permite que o avaliador troque o arquivo sem recompilar.

### Fase 2: Modelo de dados
Modelo normalizado:
- `Movie` (id, year, title, winner)
- `Producer` (id, name único)
- `Studio` (id, name único)
- relações N:N entre `Movie` e `Producer` e entre `Movie` e `Studio`

Normalizar é o que torna o cálculo por produtor confiável e é o ponto que uma revisão de código costuma cobrar.

### Fase 3: Carga do CSV
1. Um `CsvMovieLoader` disparado por `ApplicationRunner` ou `@EventListener(ApplicationReadyEvent)` dentro de uma transação.
2. Parser robusto:
   - delimitador `;`, cabeçalho ignorado, linhas vazias puladas
   - UTF-8, com e sem BOM
   - `trim` em todos os campos
   - `winner` sem diferenciar maiúsculas de minúsculas (`yes`)
3. Separar nomes com o regex `\s*,\s*|\s+and\s+`, removendo duplicados e vazios.
4. Inserir em lote, com cache de produtores e estúdios por nome para não fazer N consultas.
5. Linha malformada gera log claro, ou falha rápido. A decisão será documentada no README.

### Fase 4: Regra de negócio (`ProducerAwardIntervalService`)
1. Buscar só os filmes vencedores com seus produtores, numa única consulta com fetch join (sem N+1).
2. Agrupar os anos de vitória por produtor e ordenar.
3. Calcular os intervalos entre **vitórias consecutivas**, ou seja, cada par adjacente, não só a primeira e a última.
4. Encontrar o menor e o maior intervalo globais e devolver **todos** os empates em cada lista. O exemplo do PDF mostra exatamente isso.
5. Casos de borda a cobrir:
   - produtor com uma vitória só (não entra)
   - duas vitórias no mesmo ano (intervalo 0)
   - mesmo produtor aparecendo várias vezes em `max` ou `min`
   - nenhum intervalo disponível (listas vazias)
   - ordenação determinística por intervalo, produtor e ano
6. A complexidade fica em O(n log n).

### Fase 5: API REST (nível 2)
- `GET /api/producers/award-intervals` devolve `200` com `{min, max}`.
- Endpoints de leitura da lista, alinhados ao enunciado "leitura da lista de indicados e vencedores":
  - `GET /api/movies`, com filtros opcionais `?winner=true` e `?year=`
  - `GET /api/movies/{id}`, que devolve `200` ou `404`
- DTOs como `record` (sem expor entidades), `@RestControllerAdvice` com respostas de erro padronizadas (`ProblemDetail`), `405` e `404` corretos.

### Fase 6: Testes de integração
Com `@SpringBootTest` e `@AutoConfigureMockMvc`:
1. Contra o CSV oficial, o endpoint de intervalos devolve **exatamente** o JSON esperado (Joel Silver 1/1990/1991 e Matthew Vaughn 13/2002/2015), comparando o corpo inteiro.
2. Cenários alternativos com CSVs de teste em `src/test/resources` via `@TestPropertySource(app.csv.path=...)`:
   - empates em min e em max
   - mesmo produtor em min e em max
   - produtores separados por `,` e `and`
   - nenhum produtor com duas vitórias
3. A carga gera o total de filmes e vencedores esperado.
4. Os endpoints de filmes devolvem `200` e `404`, e cada status HTTP é verificado.

### Fase 7: Documentação e entrega
1. **README.md:**
   - pré-requisitos
   - `mvn spring-boot:run` e `mvn verify`
   - como trocar o CSV
   - exemplos de `curl`
   - console do H2
   - decisões de design
2. **Registro de IA:** um `docs/ai-interactions.md` com prompts, decisões e revisões, mais o `CLAUDE.md` do projeto. Também podemos exportar o histórico desta sessão.
3. Commits pequenos e semânticos por fase, depois push para o GitHub.

package com.outsera.razzies.producer;

import org.springframework.stereotype.Component;

import java.util.ArrayList;
import java.util.Collection;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

/**
 * Computes, for every producer with two or more wins, the interval between each pair of
 * <em>consecutive</em> wins, and returns every interval tied for the global minimum and maximum.
 * <p>
 * Runs in O(n log n) over the number of wins. Results are deterministic: ordered by producer
 * name and then by year. Two wins in the same year yield an interval of {@code 0}.
 */
@Component
public class AwardIntervalCalculator {

    public AwardIntervals calculate(Collection<ProducerWin> wins) {
        var winYearsByProducer = new TreeMap<String, List<Integer>>();
        for (ProducerWin win : wins) {
            winYearsByProducer.computeIfAbsent(win.producer(), key -> new ArrayList<>()).add(win.year());
        }

        var min = new ArrayList<AwardInterval>();
        var max = new ArrayList<AwardInterval>();
        int minInterval = Integer.MAX_VALUE;
        int maxInterval = Integer.MIN_VALUE;

        for (Map.Entry<String, List<Integer>> entry : winYearsByProducer.entrySet()) {
            List<Integer> years = entry.getValue();
            years.sort(null);
            for (int i = 1; i < years.size(); i++) {
                var interval = new AwardInterval(entry.getKey(), years.get(i) - years.get(i - 1),
                        years.get(i - 1), years.get(i));

                if (interval.interval() < minInterval) {
                    minInterval = interval.interval();
                    min.clear();
                }
                if (interval.interval() == minInterval) {
                    min.add(interval);
                }

                if (interval.interval() > maxInterval) {
                    maxInterval = interval.interval();
                    max.clear();
                }
                if (interval.interval() == maxInterval) {
                    max.add(interval);
                }
            }
        }
        return new AwardIntervals(List.copyOf(min), List.copyOf(max));
    }
}

/**
 * Optional filters of {@code GET /api/v1/movies}. Every non-null attribute narrows the result (AND).
 *
 * @param year     exact release year
 * @param winner   only winners ({@code true}) or only non-winning nominees ({@code false})
 * @param title    case-insensitive "contains" match on the title
 * @param producer case-insensitive "contains" match on any producer name
 * @param studio   case-insensitive "contains" match on any studio name
 */
public record MovieFilter(Integer year, Boolean winner, String title, String producer, String studio) {

    Specification<Movie> toSpecification() {
        List<Specification<Movie>> specs = new ArrayList<>();
        if (year != null) {
            specs.add((root, query, cb) -> cb.equal(root.get("year"), year));
        }
        if (winner != null) {
            specs.add((root, query, cb) -> cb.equal(root.get("winner"), winner));
        }
        if (hasText(title)) {
            specs.add((root, query, cb) -> cb.like(cb.lower(root.get("title")), likePattern(title)));
        }
        if (hasText(producer)) {
            specs.add((root, query, cb) -> {
                query.distinct(true);
                Join<Movie, Producer> producers = root.join("producers");
                return cb.like(cb.lower(producers.get("name")), likePattern(producer));
            });
        }
        if (hasText(studio)) {
            specs.add((root, query, cb) -> {
                query.distinct(true);
                Join<Movie, Studio> studios = root.join("studios");
                return cb.like(cb.lower(studios.get("name")), likePattern(studio));
            });
        }
        return Specification.allOf(specs);
    }

    private static boolean hasText(String value) {
        return value != null && !value.isBlank();
    }

    private static String likePattern(String value) {
        String escaped = value.strip().toLowerCase(Locale.ROOT)
                .replace("\\", "\\\\")
                .replace("%", "\\%")
                .replace("_", "\\_");
        return "%" + escaped + "%";
    }

import org.apache.commons.csv.CSVFormat;
import org.apache.commons.csv.CSVParser;
import org.apache.commons.csv.CSVRecord;

import java.io.IOException;
import java.io.Reader;
import java.io.UncheckedIOException;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.Locale;
import java.util.Set;
import java.util.regex.Pattern;

/**
 * Parses the Golden Raspberry Awards CSV: {@code year;title;studios;producers;winner}.
 * <ul>
 *     <li>Columns are located by header name (case-insensitive), so their order does not matter.</li>
 *     <li>Values are trimmed, blank lines are ignored and an UTF-8 BOM is tolerated.</li>
 *     <li>Producers are separated by {@code ","} and/or {@code " and "}; studios by {@code ","}.</li>
 *     <li>Quotes are not special: the source format does not use them and titles may contain them.</li>
 *     <li>Invalid content fails fast with the offending line number: silently dropping a row
 *     would make the award intervals wrong.</li>
 * </ul>
 */
public class MovieCsvReader {

    static final String YEAR = "year";
    static final String TITLE = "title";
    static final String STUDIOS = "studios";
    static final String PRODUCERS = "producers";
    static final String WINNER = "winner";
    private static final List<String> REQUIRED_COLUMNS = List.of(YEAR, TITLE, STUDIOS, PRODUCERS, WINNER);

    private static final Pattern PRODUCER_SEPARATOR = Pattern.compile("\\s*,\\s*(?:and\\s+)?|\\s+and\\s+");
    private static final Pattern STUDIO_SEPARATOR = Pattern.compile("\\s*,\\s*");
    private static final Set<String> TRUE_VALUES = Set.of("yes", "y", "true");
    private static final Set<String> FALSE_VALUES = Set.of("", "no", "n", "false");
    private static final char BOM = '﻿';

    private static final CSVFormat FORMAT = CSVFormat.DEFAULT.builder()
            .setDelimiter(';')
            .setQuote(null)
            .setHeader()
            .setSkipHeaderRecord(true)
            .setIgnoreHeaderCase(true)
            .setIgnoreEmptyLines(true)
            .setTrim(true)
            .setAllowMissingColumnNames(true)
            .get();

    public List<MovieCsvRecord> read(Reader source) {
        try (CSVParser parser = FORMAT.parse(skipBom(source))) {
            validateHeader(parser);
            var records = new ArrayList<MovieCsvRecord>();
            for (CSVRecord row : parser) {
                records.add(toRecord(row));
            }
            return records;
        } catch (IOException e) {
            throw new UncheckedIOException("Could not read movie CSV", e);
        } catch (IllegalStateException | IllegalArgumentException e) {
            if (e instanceof InvalidMovieCsvException invalid) {
                throw invalid;
            }
            throw new InvalidMovieCsvException("Malformed movie CSV: " + e.getMessage(), e);
        }
    }

    private static void validateHeader(CSVParser parser) {
        Set<String> header = parser.getHeaderMap().keySet().stream()
                .map(name -> name.strip().toLowerCase(Locale.ROOT).replace(String.valueOf(BOM), ""))
                .collect(java.util.stream.Collectors.toSet());
        List<String> missing = REQUIRED_COLUMNS.stream().filter(column -> !header.contains(column)).toList();
        if (!missing.isEmpty()) {
            throw new InvalidMovieCsvException("Movie CSV is missing required column(s) " + missing
                    + "; expected header: " + String.join(";", REQUIRED_COLUMNS));
        }
    }

    private static MovieCsvRecord toRecord(CSVRecord row) {
        long line = row.getParser().getCurrentLineNumber();
        String title = value(row, TITLE);
        if (title.isEmpty()) {
            throw new InvalidMovieCsvException("Line %d: title is required".formatted(line));

    private static final Logger log = LoggerFactory.getLogger(MovieImportService.class);

    private final MovieRepository movieRepository;
    private final ProducerService producerService;
    private final StudioService studioService;

    public MovieImportService(MovieRepository movieRepository, ProducerService producerService,
                              StudioService studioService) {
        this.movieRepository = movieRepository;
        this.producerService = producerService;
        this.studioService = studioService;
    }

    /** @return number of movies imported */
    @Transactional
    public int importAll(Collection<MovieCsvRecord> records) {
        // Resolve every distinct name up front: one select + one batched insert per entity type,
        // instead of one lookup per row.
        Map<String, Producer> producers = producerService.resolveByNames(
                records.stream().flatMap(r -> r.producers().stream()).toList());
        Map<String, Studio> studios = studioService.resolveByNames(
                records.stream().flatMap(r -> r.studios().stream()).toList());

        Set<String> seen = new HashSet<>();
        List<Movie> movies = new ArrayList<>(records.size());
        for (MovieCsvRecord record : records) {
            if (!seen.add(record.year() + "|" + Names.normalize(record.title()).toLowerCase(Locale.ROOT))) {
                // A duplicated row would count as a second win in the same year (interval 0).
                log.warn("Skipping duplicated movie at line {}: {} ({})", record.line(), record.title(), record.year());
                continue;
            }
            movies.add(new Movie(record.year(), Names.normalize(record.title()), record.winner(),
                    pick(producers, record.producers()), pick(studios, record.studios())));
        }
        movieRepository.saveAll(movies);
        return movies.size();
    }

    private static <T> List<T> pick(Map<String, T> byName, List<String> names) {
        return Names.normalizeAll(names).stream().map(byName::get).toList();
    }

consecutivos e o que obteve dois prêmios **mais rápido**.

## Requisitos

- **Java 21** (JDK)
- Nada mais: o Maven é baixado pelo wrapper (`mvnw`) e o banco é embarcado (H2 em memória).

## Executando

```bash
# Linux / macOS / Git Bash
./mvnw spring-boot:run

# Windows (cmd / PowerShell)
mvnw.cmd spring-boot:run
```

Ou gerando o jar:

```bash
./mvnw package
java -jar target/razzies-api-1.0.0-SNAPSHOT.jar
```

A API sobe em `http://localhost:8080`.

### Usando outro CSV

Por padrão é carregado `src/main/resources/data/movielist.csv` (cópia do `Movielist.csv` da proposta).
Para usar outro arquivo, sem recompilar:

```bash
java -jar target/razzies-api-1.0.0-SNAPSHOT.jar --razzies.data.csv-location=file:/caminho/movielist.csv
# ou
./mvnw spring-boot:run -Dspring-boot.run.arguments=--razzies.data.csv-location=file:/caminho/movielist.csv
```

Formato esperado (cabeçalho obrigatório; ordem das colunas indiferente):

```
year;title;studios;producers;winner
1980;Can't Stop the Music;Associated Film Distribution;Allan Carr;yes
```

- Produtores separados por `,` e/ou `and` (`A, B and C`, `A, B, and C`); estúdios por `,`.
- `winner`: `yes` (sem diferenciar maiúsculas) para vencedor; vazio ou `no` para indicado.
- Espaços extras, linhas em branco, BOM UTF-8 e quebras de linha `CRLF` são tolerados.
- Conteúdo inválido (ano não numérico, título vazio, coluna ausente, arquivo inexistente)
  **interrompe a inicialização** com a linha do erro, para nunca servir resultados incorretos.

## Executando os testes

O projeto contém **somente testes de integração** (`*IT.java`): cada um sobe a aplicação inteira
(carga real do CSV, JPA, H2 e camada HTTP) e valida as respostas da API.

```bash
./mvnw verify        # Windows: mvnw.cmd verify
```

| Classe | O que garante |
|---|---|
| `AwardIntervalsIT` | Resposta exata de `/award-intervals` para o CSV da proposta |
| `AwardIntervalScenariosIT` | Outros conjuntos de dados (`src/test/resources/csv`): empates em min/max, mesmo produtor em min e max, apenas vitórias **consecutivas**, indicações ignoradas, vitórias no mesmo ano, nenhum intervalo, variações de formato do CSV |
| `MovieDataLoadIT` | Carga completa (206 filmes, 42 vencedores), separação de produtores e falha de inicialização com CSV inválido |
| `MovieApiIT` | CRUD de filmes, paginação, filtros, status HTTP e corpo de erro |
| `ProducerAndStudioApiIT` | Consulta de produtores e estúdios |
